# FAQ

This directory contains short, evidence-backed answers to stable questions
about SALMON. Use a tutorial for answers that require a reproducible procedure,
and link to the authoritative SALMON2 source or SALMON-DOCS whenever possible.

Do not add entries that duplicate a tutorial or formal documentation.

Before adding an entry, obtain user approval of its topic and scope using the
[knowledge proposal template](../templates/knowledge-proposal.md). AI scientific
interpretations are proposals only; the user decides whether to adopt them.
Follow [CONTRIBUTING.md](../CONTRIBUTING.md) for drafting and human review.
